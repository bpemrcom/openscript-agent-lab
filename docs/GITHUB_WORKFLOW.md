# GitHub workflow

GitHub используется как общий журнал состояния для ChatGPT и Codex.

## Роли

- ChatGPT формирует self-contained prompt.
- Codex выполняет prompt в рабочем проекте.
- Codex сохраняет полный технический отчёт в `docs/runs/`.
- Codex делает commit и push только если prompt явно разрешает.
- ChatGPT читает отчёты из публичного GitHub repo.
- Пользователь больше не копирует длинные технические отчёты вручную, если push прошёл успешно.

## Минимальное сообщение пользователя после Codex run

Если push успешен, пользователь сообщает ChatGPT только:

`Codex запушил RUN_ID: <RUN_ID>`

## Правила безопасности

- Приватные ключи, токены и секреты не печатаются.
- Если не хватает данных или есть риск, Codex возвращает STOP.
- Один run = одна задача.
